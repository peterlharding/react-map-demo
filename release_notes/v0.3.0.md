# React Map Demo 0.3.0

This release makes the demo easier to find your way around.
The pages have names that say what they show, each one explains itself, and a new home page lists them in the order they build on each other.

## Highlights

- **A home page.**
  `/` now lists the four demos as cards, numbered in teaching order, each with a one-line summary.
  It no longer needs a Google Maps API key, so the project can be explored before a key is set up.
- **Clearer names.**
  The demos are renamed after what they show:

  | Before | Now |
  | --- | --- |
  | Mapper | Basic Map (`/basic-map`) |
  | Mapper2 | Marker (`/marker`) |
  | Map Edit | Pick a Location (`/pick-location`) |
  | Map View | My Location (`/my-location`) |

- **Every demo explains itself.**
  Each page opens with a sentence on what it demonstrates and a "Try:" hint saying what to do, such as dragging the marker and watching the coordinates change.
  Each page also sets its own browser tab title.
- **Navigation bar.**
  The links moved from the footer to a bar across the top, with "React Map Demo" leading back to the home page.
  On narrow screens it collapses into a menu that closes once a demo is chosen.
- **Faster first load.**
  The demo pages and the Google Maps library are only downloaded when a demo is first opened, so the home page loads about a third less JavaScript.

## Upgrading

Nothing is required.
Links and bookmarks to the old paths (`/mapper`, `/mapper2`, `/map-edit` and `/map-view`) redirect to the renamed demos.

If you have local changes to the page components, note that they moved and were renamed:
`src/components/Mapper.tsx` is now `src/pages/BasicMapPage.tsx`, `Mapper2.tsx` is `MarkerPage.tsx`, `MapEdit.tsx` is `PickLocationPage.tsx`, `MapView.tsx` is `MyLocationPage.tsx`, and `Footer.tsx` became `src/components/NavBar.tsx`.

## Under the hood

- `src/app/demos.ts` is the single list of demos, with each one's path, title, summary and "Try" hint.
  The home page, the navigation bar and the shared `DemoPage` heading are all built from it, so adding a demo means a list entry, a page and a route.
- Page components moved to `src/pages/`.
- The demo pages and `MapsLayout`, which wraps the Maps API loader, are lazy routes in React Router.
  This also cleared a Vite warning that the main bundle had grown past 500 kB.
- Tests now cover each demo's description and active navigation link, the home page listing, the old path redirects, and the home page working without an API key.
