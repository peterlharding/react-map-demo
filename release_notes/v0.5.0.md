# React Map Demo 0.5.0

This release adds a sixth demo, Shapes and Measuring, which draws editable lines, areas and circles and measures them as they change.
It also replaces React Router's developer error screen with a proper error page, so a failing page no longer leaves you stranded.

## Highlights

- **New demo: Shapes and Measuring (`/shapes`).**
  Pick a tool and click the map to draw:
  **Route** adds points to a line and shows its length,
  **Area** adds corners to a polygon and shows its area and perimeter,
  and **Circle** places a 1 km circle and shows its radius and area.
  All three can be on the map at once, each in its own colour.
  Drag the white handles to reshape a shape, or drag a faint handle between two points to add one, and the measurements update to match.
  **Undo last point** steps back through a route or area, and each shape can be cleared on its own.
  Distances switch between metres and kilometres, and areas between square metres, hectares and square kilometres, depending on size.
- **A friendlier error page.**
  If a page fails to load or hits an unexpected error, it is replaced by an error page that keeps the navigation bar,
  explains what happened, and offers to reload the page or go back to the demo list.
  If the page's code is missing because a newer version was deployed while the app was open, it says so and suggests reloading.
  The technical details are available in a collapsed section, with any API key hidden so the page is safe to screenshot.

## Upgrading

Nothing is required.
The app now also loads Google's `geometry` library, which is part of the Maps JavaScript API and needs no extra API enabled on your key.
Shapes are not saved, so reloading the page starts with an empty map.

## Under the hood

- `ShapesPage` uses the library's `PolylineF`, `PolygonF` and `CircleF` with `editable` options.
  Google edits a shape's own path while a handle is dragged, so the page copies the finished path back into React state on `mouseup`.
  The library's `PolygonF` `onEdit` was not used: it only watches the first path object and never removes its listeners.
- The circle follows `onCenterChanged` and `onRadiusChanged`, which also fire when React sets the circle's props, so unchanged values are ignored to avoid an update loop.
- Measurements come from `google.maps.geometry.spherical` (`computeLength` and `computeArea`), and the area's perimeter includes the closing side.
- New `formatDistance` and `formatArea` helpers in `geo.ts` use a fixed locale and choose units after rounding, so 999.6 m reads as 1.00 km rather than 1,000 m.
- `RouteErrorPage` is the `errorElement` of a pathless route around every page, inside the layout, with a fallback at the root.
  `src/app/errors.ts` holds error description, stale module detection and API key redaction.
- Tests cover drawing, measuring, undoing and clearing shapes, the unit formatting, and the error page, bringing the suite to 49 tests.
