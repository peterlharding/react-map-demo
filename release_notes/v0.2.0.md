# React Map Demo 0.2.0

This release brings the demo up to date after five years: it now builds with Vite and runs on React 19 and React Router 8.
Configuration moved into `.env`, the maps load once for the whole app, and markers use Google's current Advanced Marker API.
The four demos behave as before, with several bugs fixed along the way.

## Highlights

- **Configuration in `.env`.**
  The Google Maps API key now comes from `MAPS_API_KEY` in `.env`, alongside `HOST` and `PORT` for the dev server.
  `make setup` creates `.env` from `setup/env.template`, which documents every setting.
- **Clear feedback while the map loads.**
  A spinner shows while the Maps API loads.
  If the key is missing, or the API fails to load, the page explains what went wrong instead of showing an empty map.
- **Advanced Markers.**
  Markers use `AdvancedMarkerElement`, replacing `google.maps.Marker`, which Google has deprecated.
  A map ID is needed for these; `MAPS_MAP_ID` sets one and defaults to Google's `DEMO_MAP_ID`.
- **Map View explains your location.**
  A status line shows whether the map is centred on your location, or why it fell back to Melbourne.
- **Better navigation and layout.**
  The current page is highlighted in the navigation, `/` redirects to Map View, and unknown paths show a "Page Not Found" page.
  Maps now use the full page width.
- **Documented demos.**
  The README explains what each demo shows and how the app is put together.

## Upgrading

1. Install Node 22.22 or later.
2. Run `make setup` to create `.env`, then set `MAPS_API_KEY` to the key from your old `src/localization.ts`.
3. Delete `src/localization.ts`; it is no longer read.
4. Run `make install`, then `make dev`.
   The app is served on `HOST` and `PORT` from `.env`, not on port 3000.

## Fixed

- Map View kept asking the browser for your location after every render, re-rendering the page in a loop.
- `make dev` failed because it called an npm script that did not exist.
- The root `.env` was not gitignored, so an API key placed there could have been committed.
- The README named the key file `src/localizations.ts` instead of `src/localization.ts`.

## Under the hood

- Create React App replaced by Vite 8, with ESLint, Vitest and TypeScript 6.0.
- React 19, React Router 8 (data router), react-bootstrap 2 and Bootstrap 5.3.
- TypeScript is pinned to 6.0 because typescript-eslint does not yet support TypeScript 7.
- The Maps JavaScript API is loaded once by a shared `MapsLoader` instead of a `LoadScript` on every page.
- Shared `MapCanvas` and `AdvancedMarker` components replace the code each page repeated.
- New Makefile targets: `setup`, `build`, `preview`, `lint`, `typecheck`, `test` and `check`.
- Tests cover routing, navigation and the missing API key message.
- Create React App boilerplate and per-render console logging removed.
