# React Map Demo 0.2.1

A small patch release that tidies up how markers look after you drag them.
There are no new settings and nothing to change in an existing checkout.

## Fixed

- **Focus outline after dragging a marker.**
  Dragging a marker with the mouse or by touch left a square blue outline around it until you clicked elsewhere.
  The outline is now hidden after pointer use, and still shows when the marker is reached with Tab or moved with the arrow keys, so keyboard users can see where they are.

## Under the hood

- Google's Maps API focuses the marker after a drag in a way the browser treats as keyboard focus, so the standard `:focus-visible` CSS rule could not tell the cases apart.
  `AdvancedMarker` now records pointer use on the marker in a `data-pointer-focus` attribute, which is cleared by a key press or when the marker loses focus, and `index.css` hides the outline only while it is set.
