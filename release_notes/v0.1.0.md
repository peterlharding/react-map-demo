# React Map Demo 0.1.0

The first release: a small Create React App project exploring the `@react-google-maps/api` module.
It puts a Google Map on four pages, each trying a different combination of markers and state.

## Highlights

- **Map View** centres the map on the browser's location and shows a draggable marker with its latitude and longitude.
- **Mapper** shows a bare map centred on Melbourne.
- **Mapper2** adds a draggable marker to the Melbourne map.
- **Map Edit** shows a draggable marker and tracks its coordinates as it is moved.
- A footer links the four pages.

## Setup

Create `src/localization.ts` with your Google Maps API key:

```ts
export const GoogleMapsApiKey = "<Google Maps API key>";
```

The file is gitignored so the key is not committed.

## Under the hood

- Create React App (react-scripts 4) with TypeScript.
- React 17, React Router 5 and react-bootstrap 1 with Bootstrap 5 CSS.
