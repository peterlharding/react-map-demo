# React Map Demo 0.6.0

This release adds a seventh demo, Map State in the URL, which keeps the whole map view in the page address.
Any view can be bookmarked or shared as a link, and the browser's Back and Forward buttons step between views.

## Highlights

- **New demo: Map State in the URL (`/map-state`).**
  The address holds the map's centre, zoom and type, for example `/map-state?lat=-37.8634&lng=144.9714&zoom=16&type=satellite`,
  and the map always shows what the address says.
  - **Go to** buttons jump to Melbourne CBD, St Kilda Pier, the Dandenong Ranges and Port Phillip Bay, each with its own zoom and map type.
    Every jump adds a history entry, so Back and Forward move between them.
  - Panning and zooming update the address once the map stops moving, replacing the current history entry rather than filling the history, as Google Maps does.
  - The **Map type** picker, and the map's own Map/Satellite control, are recorded in the address too.
  - **Link to this view** shows the full address with a **Copy** button.
    Opening the link, or a bookmark of it, shows the same view.
  - Missing or invalid values in the address fall back to the default view and are corrected, so the address can always be copied as it is.
- **Navigation bar on mid-sized screens.**
  With seven demos, the bar's labels wrapped onto two lines on screens between 768 and 1200 px wide.
  It now collapses into a menu below 1200 px.

## Upgrading

Nothing is required.

## Under the hood

- `src/components/mapView.ts` parses, validates, rounds and serialises the view.
  Coordinates are rounded to 5 decimal places (about 1 m) and zoom to 2, which is what lets the map and the address settle:
  moving the map to a rounded position reads back as the same address, so each pan causes exactly one address update.
- The page writes to the address only when the rounded view has changed, and memoises the map's `center` on its coordinates, because `GoogleMap` re-centres whenever that object changes.
- `MapCanvas` gains optional `zoom`, `mapTypeId`, `onIdle` and `onMapTypeIdChanged` props.
- Tests cover parsing and rounding the view, and use a stand-in map to check presets, history entries, following the map, correcting the address and both ways of changing the map type.
  The suite now has 62 tests.
